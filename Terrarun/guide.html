TerraRun 테스트 안내

달리는 길 앞에 오르막이 다가오면 차량 내비처럼 미리 알려 주는 러닝 오디오 코치 시험판이에요. PC에서 한 번 보고, 폰으로 한 번 실제로 뛰어 주시면 됩니다. 솔직한 답이 가장 큰 도움이에요.

테스트 화면 열기 →

앱 설치·가입은 없어요. 위치는 내 기기 안에서만 계산하고, 기록도 내 기기에만 남아요.

① PC에서 보기 (5~10분, 크롬·엣지)

A. 추천 코스 시뮬레이션

  1. 스피커나 이어폰 소리를 켜고 테스트 화면을 엽니다.
  2. 위쪽 추천 탭 → 지도를 끌어서 아는 동네로 옮기고 지도 가운데에서를 누릅니다(10~20초).
  3. 코스 3개가 나오면 하나에서 이 코스를 누릅니다.
  4. 음악: 내 음악 파일 → 파일 고르기로 PC에 있는 음악 1~3곡을 고르거나, 음악 없이를 고릅니다.
  5. 시뮬레이션 속도 2배 → 시뮬레이션. 지도에서 주황 점이 코스를 달려요. 오르막 앞에서 "200미터 앞, 오르막이에요" 같은 안내가 나오고, 그동안 음악이 작아져요.
  6. 2~3분 보다가 끝내기.

B. 코스 없이 달리기 시뮬레이션

  1. 위쪽 자유 탭 → 지도를 아는 동네로 옮기고 지도 가운데에서 시뮬레이션.
  2. 초록 선 = 앞으로 내다본 400 m 길, 보라 = 오르막. 가상 주자가 아무 길로나 달리며 앞 오르막을 미리 말해요.

길 지도 서버가 붐비면 "서버 1/3번째 시도 중…"이 뜨고 실패할 수 있어요. 잠시 뒤 다시 누르거나 그대로 알려 주세요(그것도 시험 결과예요).

윈도우에 한국어 음성이 없으면 숫자 안내가 안 나오거나 어색하게 읽힐 수 있어요. 그렇게 들리면 "답 보내기"에 적어 주세요.

② 아이폰으로 실제로 뛰기 (15~30분)

뛰기 전 준비
  • 링크는 Safari로 엽니다. 카톡에서 누르면 카톡 안에서 열리니 오른쪽 아래 ⋯ 또는 공유 → Safari로 열기.
  • 무음 모드를 끕니다(옆 스위치). 무음이면 안내 소리가 안 날 수 있어요.
  • 설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함. 화면이 꺼지면 위치가 멈춰요. 끝나고 꼭 되돌리세요.
  • 위치 권한을 물으면 허용.

둘 중 편한 방식으로

  1. 코스 없이(추천): 출발할 곳에서 자유 탭 → 내 위치에서 시작. 10~20초 뒤 "전방 안내를 시작할게요"가 나오면 평소처럼 아무 길이나 뛰세요.
  2. 정해진 코스: 추천 → 시간 고르고 추천 3개 만들기 → 이 코스 → 달리기 시작. 그 코스를 따라 뛰어요.
  • 폰은 손이나 암밴드에, 화면을 켠 채로 둡니다.
  • 음악은 멜론·스포티파이 같은 음악 앱을 먼저 틀어 두세요. 안내 때 음악이 멈추는지, 작아지는지, 그대로 겹치는지 봐 주세요.
  • 끝나면 끝내기 → 아래 ③ 답 보내기.
차도·횡단보도에서는 안내보다 주변을 먼저 보세요. 이어폰은 한쪽만 쓰거나 오픈형을 권해요.

② 안드로이드로 실제로 뛰기 (15~30분)

뛰기 전 준비
  • 링크는 크롬으로 엽니다. 카톡에서 누르면 오른쪽 위 ⋮ → 다른 브라우저로 열기.
  • 위치 권한을 물으면 허용(정확한 위치). 폰 위치(GPS)가 켜져 있는지 확인.
  • 화면은 페이지가 켜 둡니다. 그래도 꺼지면 설정 → 디스플레이 → 화면 자동 꺼짐을 10분으로(끝나고 되돌리기).
  • 미디어 음량을 올려 둡니다.

둘 중 편한 방식으로

  1. 코스 없이(추천): 출발할 곳에서 자유 탭 → 내 위치에서 시작. 10~20초 뒤 "전방 안내를 시작할게요"가 나오면 평소처럼 아무 길이나 뛰세요.
  2. 정해진 코스: 추천 → 시간 고르고 추천 3개 만들기 → 이 코스 → 달리기 시작.
  • 폰은 손이나 암밴드에, 화면을 켠 채로 둡니다. 다른 앱으로 넘어가면 위치가 멈춰요.
  • 음악은 음악 앱을 먼저 틀어 두세요. 안내 때 음악이 어떻게 되는지 봐 주세요.
  • 끝나면 끝내기 → 아래 ③ 답 보내기.
차도·횡단보도에서는 안내보다 주변을 먼저 보세요. 이어폰은 한쪽만 쓰거나 오픈형을 권해요.

③ 답 보내기

해 본 것만 답하면 돼요. 다 고르고 맨 아래 답 복사 → 카톡에 붙여 보내 주세요. 이 페이지는 답을 어디에도 보내지 않아요.



뛴 기록(선택)
테스트 화면 내 코스 탭 → 지난 기록에서 안내 기록 CSV·GPX를 받아 보내 주시면 "안내가 몇 m 일찍/늦게 나왔는지"를 잴 수 있어요. 위치 기록이라 원할 때만 보내 주세요. 받은 기록은 분석에만 쓰고 30일 안에 지웁니다.
